# قالب وردپرس «کاتالیزور»

قالب اختصاصی معرفی و فروش دوره برای دکتر سینا رضادوست (برند کاتالیزور).
فارسی، راست‌به‌چپ، **تم تیره** زغالی/کهربایی هماهنگ با لوگو، پس‌زمینه‌ی انیمیشنیِ
**شبکه‌ی کربن (گرافن)** که دور نشانگر جمع و روشن می‌شود، چیدمانِ عریض روی نمایشگرهای بزرگ،
و سازگار با ووکامرس. با نسخه‌ی استاتیکِ `index.html` یکی است.

## نصب

1. کل پوشه‌ی `catalyzer/` را در `wp-content/themes/` بگذارید
   (یا از همین پوشه یک فایل zip بسازید و از پیشخوان → **نمایش → پوسته‌ها → افزودن → بارگذاری پوسته** نصب کنید).
2. پوسته را فعال کنید.
3. **تنظیمات → خواندن** → «صفحهٔ اصلی نمایش دهد» را روی **یک برگهٔ ثابت** بگذارید و یک برگهٔ خالی به نام «خانه» بسازید و انتخاب کنید. (یا همان «آخرین نوشته‌ها» را نگه دارید؛ قالب در هر دو حالت صفحهٔ فرود را نشان می‌دهد.)
4. **تنظیمات → پیوندهای یکتا** را یک بار ذخیره کنید تا آدرس دوره‌ها/ویدیوها فعال شود.

## محتوا از کجا ویرایش می‌شود؟

| بخش | محل ویرایش |
| --- | --- |
| همهٔ متن‌ها و تصاویر صفحهٔ فرود (هیرو، آمار، درباره، رزومه، متد، سربرگ بخش‌ها، فراخوان، تماس، فوتر) | **نمایش → سفارشی‌سازی → «کاتالیزور — محتوای صفحهٔ فرود»** |
| لوگو | سفارشی‌سازی → **هویت سایت → لوگو** (اگر خالی بماند، نشان SVG برند نمایش داده می‌شود) |
| منوی هدر و فوتر | **نمایش → فهرست‌ها** (جایگاه‌های «منوی اصلی» و «منوی فوتر»). اگر فهرستی نسازید، لینک‌های پیش‌فرضِ لنگر (#about و…) نمایش داده می‌شود. |
| دوره‌ها و پکیج‌ها | پیشخوان → **دوره‌ها** (نوع محتوای `course`). سه دورهٔ اول در صفحهٔ اصلی می‌آید؛ ترتیب با فیلد «ترتیب» در جعبهٔ «ویژگی‌های برگه». دورهٔ ویژه را با تیک «کارت ویژه» مشخص کنید. |
| ویدیوهای کلاس | پیشخوان → **ویدیوهای کلاس** (نوع محتوای `lesson`). آدرس یوتیوب/اپارات را در فیلد «آدرس ویدیو» بگذارید؛ تصویر شاخص = بندانگشتی. |
| نظرات دانش‌آموزان | پیشخوان → **نظرات** (نوع محتوای `testimonial`). عنوان = خط معرفی، متن = نقل‌قول. |
| درخواست‌های فرم تماس | پیشخوان → **درخواست‌های مشاوره** + ارسال ایمیل به مدیر سایت. |

## فروش دوره و پرداخت (ووکامرس)

1. افزونهٔ **WooCommerce** را نصب و درگاه پرداخت ایرانی (مثل زرین‌پال) را اضافه کنید.
2. برای هر پکیج یک **محصول** بسازید (نوع «محصول مجازی/دانلودی»).
3. در پیشخوان → دوره‌ها → آن دوره، فیلد **«لینک دکمه»** را روی آدرس همان محصول یا لینک «افزودن به سبد» بگذارید.
   به این ترتیب کارت دوره در صفحهٔ فرود به صفحهٔ خرید وصل می‌شود.
4. صفحهٔ فروشگاه/محصول به‌صورت خودکار با استایل قالب هماهنگ است.

> جایگزین: می‌توانید به‌جای نوع محتوای «دوره»، مستقیماً از صفحهٔ فروشگاه ووکامرس استفاده کنید؛
> در آن صورت بخش «دوره‌ها»ی صفحهٔ فرود را از سفارشی‌سازی خاموش کنید و یک آیتم منو به فروشگاه اضافه کنید.

## فرم تماس

- فرم داخلی نیازی به افزونه ندارد؛ پیام‌ها هم ذخیره می‌شوند هم ایمیل می‌شوند.
- برای استفاده از **Contact Form 7** یا هر فرم دیگری: سفارشی‌سازی → تماس → «شورت‌کد فرم» را پر کنید؛ جایگزین فرم داخلی می‌شود.
- ایمیلِ مقصد: سفارشی‌سازی → تماس → «ایمیل دریافت درخواست‌ها» (خالی = ایمیل مدیر سایت). برای تحویل مطمئن، افزونهٔ SMTP توصیه می‌شود.

## نکات

- **زبان سایت** را در تنظیمات روی «فارسی» بگذارید تا اعداد و تاریخ درست شود.
- تصویر پیش‌نمایش پوسته (`screenshot.png`) عمداً همراه نیست؛ در صورت نیاز یک تصویر ۱۲۰۰×۹۰۰ با همین نام در ریشهٔ پوسته بگذارید.
- فونت‌ها از Google Fonts بارگذاری می‌شوند؛ برای حریم خصوصی/سرعت می‌توانید با افزونهٔ OMGF آن‌ها را میزبانی محلی کنید.
- پس‌زمینهٔ انیمیشنی به‌صورت خودکار برای کاربرانِ «کاهش حرکت» ساکن می‌شود و هنگام مخفی‌بودن تب متوقف می‌شود.
